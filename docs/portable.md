# Portable-сборка FancyWM

## Повторная упаковка

В Windows, с установленными Git, .NET SDK 10 и необходимыми компонентами
Windows SDK/WPF, выполните из корня репозитория:

```powershell
pwsh -File scripts/Build-Portable.ps1
```

Для другого каталога вывода, включая путь с пробелами:

```powershell
pwsh -File scripts/Build-Portable.ps1 -OutputRoot "E:\FancyWM test builds"
```

Скрипт определяет репозиторий по своему расположению, поэтому его также можно
вызвать по абсолютному пути из другого рабочего каталога. Он вызывает существующий
`Apply-DependencyPatches.ps1 -Mode Apply`: проверяет уже применённые патчи или
применяет их к ожидаемой чистой базе; конфликтующие изменения не перезаписывает.
Затем локально выполняет `dotnet publish` для GUI и CLI: Release win-x64,
self-contained, с restore, без single-file и trimming. Версии SDK, зависимостей
и gitlink скрипт не меняет.

Каждый запуск создаёт отдельную папку и ZIP с отметкой времени в
`artifacts/portable` (либо OutputRoot), README с версией/исходным commit и файл
`.zip.sha256`. Предыдущие пакеты не перезаписываются. README отмечает изменения
отслеживаемых файлов рабочего дерева, если они есть; для повторения сохранённого
исходного состояния собирайте из нужного commit. Применённые патчи зависимости
описывает существующий manifest.

## BAT и запуск

1. Распакуйте весь ZIP в отдельную папку.
2. Завершите другую копию FancyWM через значок в трее.
3. Запустите `FancyWM-GUI.exe`.

.NET Runtime включён. Настройки и журналы используют `%APPDATA%\FancyWM`.
`FancyWM.bat` запускает `"%~dp0FancyWM.exe" %*` и возвращает `%ERRORLEVEL%`.
Рабочий каталог менять не требуется; пути с пробелами поддерживаются.
CLI-вывод сохраняется. Для проверки без обычного UI доступны `--help`/`--version`.

BAT попадает в пакет через существующий `CopyToOutputDirectory=PreserveNewest`
в `FancyWM.csproj`; скрипт проверяет совпадение SHA-256 исходного и упакованного
файлов. Отдельной подмены BAT после сборки больше нет.

## Статус и границы

Обе новые фичи и предыдущие оптимизации подтверждены пользователем на версии
2.19.1.7: «Все работает как надо». Это не подтверждает отдельно не заявленные
мониторы, DPI и приложения. Текущий этап касается только BAT и упаковки;
правила layout не менялись, повторный интерактивный UI-проход не нужен.
Старые локальные архивы и receipts отсутствуют; они не восстанавливаются и
не предлагаются как доступные для скачивания.
