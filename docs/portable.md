## Запуск

1. Распакуйте весь ZIP в отдельную папку.
2. Если запущена другая копия FancyWM, завершите её через значок в трее.
3. Запустите `FancyWM-GUI.exe` из распакованной папки.

Отдельная установка .NET не требуется. Настройки и журналы остаются в
`%APPDATA%\FancyWM`; portable использует текущие пользовательские настройки.
Для CLI доступны `FancyWM.exe --help` и `FancyWM.exe --version`.
Инструкция `README.ru.md` и сведения об исходниках/патчах `BUILDINFO.json`
также находятся внутри ZIP. Упакованный `FancyWM.bat` исправлен на запуск
фактически включённого `FancyWM.exe`; исходный файл репозитория не менялся.
