## Запуск

1. Распакуйте весь `FancyWM-Portable-win-x64-20260913-214722.zip` в отдельную папку.
2. Если другая копия FancyWM уже запущена, завершите её через значок в трее.
3. Запустите `FancyWM-GUI.exe` из распакованной папки.

Это Release x64 для Windows 10/11 со встроенным .NET; установка .NET отдельно
не требуется. Настройки и журналы хранятся в `%APPDATA%\FancyWM`, поэтому
portable использует существующие пользовательские настройки.

Архив находится в `artifacts/portable/`, вне Git. Проверенная версия —
`2.19.1.2`, 509 файлов, размер ZIP — 74 737 069 байт.

Архив сохранён без пересборки и переупаковки. Ранее проверены хеши каждого

## Границы проверки

Предыдущие успешные Debug/Release тесты, GUI/x64/MSIX сборки и ограниченные
автоматизированные UI-проверки сохраняют свой результат. При сохранении
изменений в Git приложение и полная регрессия повторно не запускались.

Общее подтверждение не заменяет отдельных проверок DPI, нескольких мониторов,
Horizontal/right-master MoveRight, размещения Firefox, физических жестов
фокуса/перетаскивания и переноса/переполнения виртуальных рабочих столов.
Они остаются дополнительными проверками. Для проверки переноса между
мониторами и смешанного DPI нужен второй дисплей; текущая среда — один
монитор 3440×1440 при 96 DPI. При сборке сохраняются ранее известные
предупреждения компилятора и зависимостей.

Исследования GPU, памяти и дополнительные оптимизации отложены. Исторические
результаты и ссылки на локальные свидетельства сохранены в
`PERFORMANCE_TODO.md`, `PERFORMANCE_STATUS.md` и `IMPLEMENTATION_STATUS.md`.
Большой сырой журнал `docs/performance/OPTIMIZATION_MEASUREMENTS.csv`, дампы,
ETL, локальные профили, резервные копии и бинарные артефакты остаются локально
вне Git; историческим измерительным скриптам могут требоваться эти файлы.
