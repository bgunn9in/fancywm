## Реализовано

- Horizontal/Vertical: направленное движение к непосредственно соседнему master выполняет promotion с точным замещением освобождённого места. Промежуточный satellite нельзя перескочить. Master меняет сторону с сохранением роли, фокуса и внутреннего порядка группы. Обе стороны зеркальны.
- `UseMixedSatellites`, по умолчанию `false`: при трёх satellite дерево содержит вертикальную панель `[Horizontal(V1,V2), H]`. Верхняя пара получает 2/3 высоты, H — 1/3, с ограничениями Flex/MinSize и существующими отступами. При другом количестве сохраняется обычная ориентация.
- В смешанной схеме направленные команды и drag-and-drop обменивают ровно двух участников. H → вверх выбирает ближайшего верхнего соседа; при равенстве и погрешности округления в один пиксель — V1. Окно получает геометрию нового места, третье сохраняет свою геометрию.
- `ToggleFocusedSatelliteSlot` доступна в Keybindings как **Switch upper / wide satellite slot**, без занятого по умолчанию сочетания. Поддержаны обычный обработчик и direct hotkeys, маршрутизация по активному дисплею. Старая команда ориентации сохранена отдельно.
- Мышь: satellite на master выполняет promotion; master через границу меняет сторону. Preview и mouse-up используют один engine и актуальные ограничения, устаревшие планы отклоняются.
- Настройка сохраняется и применяется через существующий lifecycle. WPF preview показывает смешанную схему при отображении трёх satellite. Minimize/restore, float/unfloat, закрытие, добавление и capacity shrink сохраняют порядок оставшихся окон.

Canonical invariant расширен только для указанной формы. Существующий engine, SplitPanelNode/Flex, coordinator, state по desktop/display, preflight и rollback сохранены. Невозможные обмены и настройки отклоняются атомарно; невозможное добавление использует прежний overflow.
